# Sokchad App

Sokchad is a mobile marketplace platform for buying and selling digital and physical products. Built with React Native and Expo, it delivers seamless cross-platform performance across iOS, Android, and Web.

## Features

- 🛍️ Product listings with categories
- 💬 In-app messaging between buyers and sellers
- 🏪 Seller dashboard with analytics
- 🔐 Admin panel with staff management & permissions
- 🌍 Multilingual support (English, Français, العربية)
- 💳 Multiple payment methods
- ✅ User verification system
- 📊 Admin dashboard with full statistics

## Getting Started

### 1. Install Dependencies

```bash
npm install
# or
pnpm install
```

### 2. Start the Project

```bash
npm run start         # Start Expo development server
npm run android       # Launch Android emulator
npm run ios           # Launch iOS simulator
npm run web           # Start the web version
```

### 3. Lint the Code

```bash
npm run lint
```

## Tech Stack

- React Native: 0.79
- React: 19.0.0
- Expo: ~53
- Expo Router: ~5.0
- Backend: PHP + MySQL (see `/backend`)
- Auth: Supabase (Authentication only)
